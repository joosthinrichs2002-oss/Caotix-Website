# CAOTIX EP Easter-Egg-Kampagne

Dieser Ordner enthält die zeitlich begrenzte EP-Kampagne. Das CTX-Minispiel unter `n8k2p/` ist **dauerhaft** und gehört nicht zur zu entfernenden Kampagne. Nur der darin platzierte Boxsack (`The Fight`) ist ein Kampagnen-Plugin.

## Nach Kampagnenende

1. In `script.js` den markierten Block `CAOTIX EP EASTER-EGG CAMPAIGN LOADER` entfernen.
2. In `n8k2p/index.html` genau diese eine markierte Script-Zeile entfernen: `../easter-eggs/the-fight.js`. Dadurch verschwindet nur der Boxsack; das CTX-Spiel bleibt vollständig erhalten.
3. Den Ordner `q4m7v/` löschen (`Fear to Die`).
4. Den kompletten Ordner `easter-eggs/` löschen.
5. Optional `merch_preview.html` löschen.

`n8k2p/` **nicht löschen**.
